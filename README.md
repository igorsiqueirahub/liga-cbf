# Liga do Futebol do Brasil – 4ª reunião

Página: https://igorsiqueirahub.github.io/liga-cbf/

Página interativa para embed (iframe) com os dados da apresentação da CBF na 4ª Reunião da
Liga do Futebol do Brasil (setembro de 2026): tempo de jogo, calendário 2026, inscrição de
atletas (aprovados: limite de estrangeiros e Lista A/B) e padronização dos horários das Séries A e B (aprovada).

Mesmo modelo do painel `dividas-clubes`: visual vermelho/preto, Figtree, altura automática no iframe.

## Como embedar

Copie o conteúdo de [`embed.html`](embed.html) para o código-fonte da sua página.
Aba no `#`: `#atletas` (padrão), `#horarios`, `#tempo`, `#calendario`, `#contexto`
(`#aba=horarios` também funciona).
